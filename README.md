# 🎓 SPPU Student Website

A modern student resource marketplace built for **Savitribai Phule Pune University (SPPU)** where students can discover, organize, and share academic resources including notes, PYQs, practicals, assignments, and study material.

Designed with a clean and responsive interface, the platform focuses on making academic resources easier to find through a structured catalogue instead of scattered file sharing.

---

## ✨ Features

* 📚 Browse academic resources by category
* 🏛️ Dedicated SPPU branch navigation
* 📖 Semester-wise subject organization
* 🔍 Search resources quickly
* 📄 Resource catalogue with notes, PYQs, practicals, and assignments
* ⬆️ Upload academic resources
* 👤 User authentication
* 📱 Fully responsive UI
* ⚡ Fast performance using Vite
* 🔥 Firebase backend integration

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/IamTejaschinchole/sppu_student_website.git
```

Move into the project

```bash
cd sppu_student_website
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

---

## 🔥 Firebase Setup

Create a `.env` file in the project root and configure your Firebase credentials.

Example:

```env
VITE_FIREBASE_API_KEY=YOUR_API_KEY
VITE_FIREBASE_AUTH_DOMAIN=YOUR_PROJECT.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=YOUR_PROJECT_ID
VITE_FIREBASE_STORAGE_BUCKET=YOUR_PROJECT.appspot.com
VITE_FIREBASE_MESSAGING_SENDER_ID=YOUR_SENDER_ID
VITE_FIREBASE_APP_ID=YOUR_APP_ID
```

1. Browse available academic categories.
2. Select an SPPU branch.
3. Choose the semester.
4. Open the desired subject.
5. View available resources.
6. Upload and share study materials.
