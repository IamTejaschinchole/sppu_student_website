school About this resource

These are my personal complete handwritten lecture and revision notes for Data Structures (SPPU Course Code 210243), prepared during my 2nd year Semester 3 at Pune Institute of Computer Technology (PICT).

It thoroughly addresses all 6 units mandated by the Savitribai Phule Pune University syllabus. Every abstract concept is complemented by pencil-and-pen pointer diagrams, memory stack allocations, step-by-step tree rebalancing dry runs, and actual handwritten C++ implementations alongside algorithm pseudo-code.

Unit 1 & 2: Fundamentals & Stacks/Queues

Linear data structures, pointer mechanics, infix to postfix conversions, monotonic queue paradigms, and circular buffer algorithms.

Unit 3 & 4: Non-Linear Trees & BST

Complete traversals (Inorder, Preorder, Postorder, Morris traversal), AVL balance factor calculations, and threaded binary trees.

Unit 5: Graph Theory & Spanning Trees

BFS, DFS, Prim’s & Kruskal’s Minimum Spanning Tree with union-find disjoint sets, topological sort, and Dijkstra’s shortest path.

Unit 6: Hashing & Search Structures

Hash collision strategies, double hashing, quadratic probing, B-Trees index node splitting, and external sorting mechanics.
